8BitDo PCE 2.4G 手把——韌體說明
=============================

此手把支援兩種不同的韌體類型：

1) 標準 8BitDo PCE 2.4G 韌體（「原廠」）
2) 適用於 Analogue 主機的特殊 Analogue 韌體（例如 Analogue Duo）

如果你要變更韌體，請先閱讀本文。


1. 韌體類型
-----------

A) 原廠 PCE 2.4G 韌體

- 與隨附的 2.4G USB 接收器搭配使用。
- 無線通訊方式為：手把 <-> USB 接收器。
- 刷寫原廠韌體後，你必須再次將手把與 USB 接收器重新配對（見第 7 節）。

B) Analogue 韌體

- 為 Analogue 系統（例如 Analogue Duo）設計。
- 手把會直接連接到 Analogue 主機的 2.4G 無線模組。
- 執行 Analogue 韌體時，不會使用隨附的 2.4G USB 接收器。
- 如果之後切回原廠韌體，手把將不再直接與 Analogue 主機通訊，必須重新與 USB 接收器配對。


2. 進入韌體更新模式（手把）
---------------------------

當你想要更換韌體（原廠或 Analogue）時，請使用以下步驟：

1. 確保手把處於關閉狀態。
2. 按住 ``SELECT`` 鍵。
3. 在按住 ``SELECT`` 的同時，短按一次 ``HOME`` 鍵，然後立即同時放開這兩個按鍵。
4. 檢查藍燈和綠燈是否同時閃爍（同步閃爍）。

   - 藍燈和綠燈同時閃爍 = 韌體更新模式。

5. 使用 USB 線將手把連接到電腦。
6. 電腦上會出現一個新的 USB 隨身碟（這是手把的內部儲存空間）。

現在你可以將相應的韌體檔案複製到這個隨身碟中。


3. 安裝原廠韌體（標準 PCE 2.4G）
--------------------------------

本節說明如何安裝或重新安裝標準原廠韌體。

1. 將手把置於韌體更新模式（見第 2 節）。
2. 在電腦上開啟網頁瀏覽器並前往::

      https://support.8bitdo.com/

3. 下載 PCE 2.4G 原廠韌體套件，例如::

      8BitDo_PCE_Fw_V405.zip

   如有需要，可使用直接連結::

      https://download.8bitdo.com/Firmware/Controller/PCE-2.4g/8BitDo_PCE_Fw_V405.zip

4. 解壓縮 ZIP 檔案。
5. 在解壓縮後的目錄中，找到手把韌體檔案，例如::

      8BitDo_PCE_Fw_V405/Controller/PCE_24G_GamePad_V4.05.dat

6. 將手把韌體檔案（例如 ``PCE_24G_GamePad_V4.05.dat``）
   複製到手把隨身碟的根目錄。
7. 等待幾分鐘，讓更新完成。
8. 在作業系統中安全移除該隨身碟。
9. 拔除 USB 線。
10. 在未連接 USB 的情況下，按住 ``HOME`` 鍵約 3 秒，讓手把完全離開升級模式 / 關機。
11. 如有需要，再正常開機。


4. 安裝 Analogue 韌體（供 Analogue 主機使用）
---------------------------------------------

本節說明如何安裝或重新安裝 Analogue 專用韌體，以便直接用於 Analogue 系統（例如 Analogue Duo）。

1. 將手把置於韌體更新模式（見第 2 節）。
2. 在電腦上開啟網頁瀏覽器並前往::

      https://support.8bitdo.com/analogue/Dock/

3. 下載此手把對應的 Analogue 韌體套件，例如::

      PCE_Fw_V5_01_For_Analogue.zip

   如有需要，可使用直接連結::

      https://download.8bitdo.com/Firmware/analogue/Dock/2.4g/PCE_Fw_V5_01_For_Analogue.zip

4. 解壓縮 ZIP 檔案。
5. 在解壓縮後的目錄中，找到韌體檔案，例如::

      PCE_Fw_V5_01_For_Analogue/PCE_Fw_V5_01_For_Analogue.dat

6. 將 Analogue 韌體檔案（例如 ``PCE_Fw_V5_01_For_Analogue.dat``）
   複製到手把隨身碟的根目錄。
7. 等待幾分鐘，讓更新完成。
8. 在作業系統中安全移除該隨身碟。
9. 拔除 USB 線。
10. 按住 ``HOME`` 鍵約 3 秒，直到所有 LED 熄滅。
11. 升級完成。

安裝 Analogue 韌體後，手把將直接與 Analogue 主機的 2.4G 系統配對，
不會使用隨附的 2.4G USB 接收器。


5. 將手把與 Analogue Duo / Analogue Dock 配對
---------------------------------------------

當手把執行 Analogue 韌體時，請使用以下步驟將其與 Analogue 無線系統配對：

1. 按 ``HOME`` 鍵開啟手把。
2. 按住 ``SELECT`` 鍵約 3 秒。

   - 藍燈會開始快速閃爍。

3. 按下 Analogue Dock / Analogue Duo 上的配對按鈕。
4. 配對成功後，手把的藍燈會恆亮。
5. 首次成功配對後，下次通常會自動重新連線。


6. 讓 USB 接收器進入韌體更新模式
--------------------------------

2.4G USB 接收器也有自己的韌體，並且可以更新。

重要說明：

- 只有當手把執行原廠韌體，並且正在與接收器通訊時，才能讓接收器進入更新模式。
- 使用 Analogue 韌體時，不會使用接收器，因此無法透過手把觸發接收器的更新模式。

要讓 USB 接收器進入韌體更新模式：

1. 確保手把正在使用原廠韌體，並且能夠連接到接收器。
2. 將 2.4G USB 接收器插入電腦。
3. 按 ``HOME`` 鍵開啟手把。

   - 等待手把與接收器建立連線（接收器指示燈應為恆亮，而不只是閃爍）。

4. 現在同時按住手把上的以下三個按鍵::

      SELECT + RUN + HOME

5. 持續按住這三個按鍵，直到電腦上出現一個新的 USB 隨身碟。

   - 這個新出現的裝置，就是處於韌體更新模式的 USB 接收器。

接收器韌體檔案位置（原廠 v4.05 套件）：

- 解壓縮原廠韌體 ZIP（``8BitDo_PCE_Fw_V405.zip``）後，
  接收器韌體檔案位於::

      8BitDo_PCE_Fw_V405/Receiver/PCE_24G_RR_V4.05.dat

6. 開啟新出現的隨身碟（接收器）。
7. 將接收器韌體檔案::

      PCE_24G_RR_V4.05.dat

   複製到接收器隨身碟的根目錄。
8. 等待幾分鐘，讓更新完成。
9. 在作業系統中安全移除該隨身碟。
10. 如有需要，拔下 USB 接收器後再重新插入。

完成後，USB 接收器就會執行更新後的韌體。


7. 將手把重新與 USB 接收器配對（在使用 Analogue 韌體之後）
------------------------------------------------------------

每當你從 Analogue 韌體切回原廠韌體時，都必須重新將手把與其 USB 接收器配對。
否則，它們將無法進行無線連線。

將手把與 USB 接收器配對的方法如下：

1. 將 2.4G USB 接收器插入你的 PC 或主機。

   - 接收器的藍燈會閃爍。

2. 按 ``HOME`` 鍵開啟手把。
3. 按住 ``SELECT`` 鍵約 3 秒。

   - 手把的藍燈會開始快速閃爍。

4. 將手把靠近接收器。
5. 配對成功後，手把和接收器上的藍燈都會保持恆亮（穩定藍燈）。

完成此步驟後，手把與接收器就會在原廠韌體下同步。


8. 復原 / 解磚說明（實務觀察）
------------------------------

這些說明是根據韌體復原過程中觀察到的真實恢復行為整理而成。

1. 如果手把仍然能夠進入韌體更新模式，並且會掛載成一個 USB 隨身碟，
   那麼開機載入程式很可能仍然完好。

2. 複製完韌體檔案後，一定要先在作業系統中安全移除手把隨身碟，拔除 USB 線，
   然後再在未連接 USB 電源的情況下按住 ``HOME`` 約 3 秒。

3. 在一次復原案例中，從 Windows 刷寫可以正常成功，而從 Linux 刷寫後，
   即使已經正確同步並卸載，手把仍然沒有反應。因此，對這個特定手把而言，
   在韌體刷寫失敗後的復原情境下，Windows 是更安全的選擇。

4. 如果手把在變更韌體後看起來像「死機」了一樣，先讓它充電更久一些，
   再判斷它是否真的變磚。電量過低可能會誤導診斷。

5. 在一次韌體切換失敗的案例中，正常的手把更新組合鍵
   （``SELECT + HOME``）已經失效。然而，按住 ``SELECT + RUN + HOME``
   幾秒後，手把重新進入了韌體更新模式，藍燈和綠燈同時閃爍。之後，
   將手把連接到 Windows 機器並重新刷寫韌體，復原成功。

6. ``SELECT + RUN + HOME`` 的官方用途，是在手把執行原廠韌體並且已連接接收器時，
   讓接收器進入韌體更新模式。然而，在上面描述的復原案例中，
   這個組合鍵同樣讓手把本體重新回到了韌體更新模式。這個現象應被視為一種實務上的復原觀察，
   而不是官方記錄的手把復原方法。


9. 在原廠韌體與 Analogue 韌體之間切換（總結）
---------------------------------------------

- 如果你想讓手把直接與 Analogue 主機搭配使用（不使用 USB 接收器）：

  - 安裝 Analogue 專用韌體（見第 4 節）。
  - 按第 5 節中的步驟，將其與 Analogue Dock / Duo 配對。

- 如果你想讓手把與隨附的 2.4G USB 接收器搭配使用：

  - 安裝原廠 PCE 2.4G 韌體（見第 3 節）。
  - 可選地更新 USB 接收器韌體（見第 6 節）。
  - 然後按第 7 節中的步驟，重新將手把與接收器配對。

請務必記住：

- Analogue 韌體 = 直接連接 Analogue 主機（不使用接收器）。
- 原廠韌體 = 使用 USB 2.4G 接收器，並且必須與之配對。

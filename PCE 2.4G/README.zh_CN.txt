8BitDo PCE 2.4G 手柄——固件说明

此手柄支持两种不同的固件类型：

1)  标准 8BitDo PCE 2.4G 固件（“原厂”）
2)  面向 Analogue 主机的特殊 Analogue 固件（例如 Analogue Duo）

如果你要更改固件，请先阅读本文。

1. 固件类型

A)  原厂 PCE 2.4G 固件

-   与随附的 2.4G USB 接收器配合使用。
-   无线通信方式为：手柄 <-> USB 接收器。
-   刷写原厂固件后，你必须再次将手柄与 USB 接收器配对（见第 7 节）。

B)  Analogue 固件

-   为 Analogue 系统（例如 Analogue Duo）设计。
-   手柄会直接连接到 Analogue 主机的 2.4G 无线模块。
-   运行 Analogue 固件时，不会使用随附的 2.4G USB 接收器。
-   如果之后切回原厂固件，手柄将不再直接与 Analogue 主机通信，必须重新与
    USB 接收器配对。

2. 进入固件更新模式（手柄）

当你想要更换固件（原厂或 Analogue）时，请使用以下步骤：

1.  确保手柄处于关闭状态。
2.  按住 SELECT 键。
3.  在按住 SELECT 的同时，短按一次 HOME 键，然后立即同时松开这两个按键。
4.  检查蓝灯和绿灯是否同时闪烁（同步闪烁）。
    -   蓝灯和绿灯同时闪烁 = 固件更新模式。
5.  使用 USB 线将手柄连接到电脑。
6.  电脑上会出现一个新的 USB U 盘（这是手柄的内部存储）。

现在你可以将相应的固件文件复制到这个 U 盘中。

3. 安装原厂固件（标准 PCE 2.4G）

本节说明如何安装或重新安装标准原厂固件。

1.  将手柄置于固件更新模式（见第 2 节）。

2.  在电脑上打开网页浏览器并访问:

        https://support.8bitdo.com/

3.  下载 PCE 2.4G 原厂固件包，例如:

        8BitDo_PCE_Fw_V405.zip

    如有需要，可使用直链:

        https://download.8bitdo.com/Firmware/Controller/PCE-2.4g/8BitDo_PCE_Fw_V405.zip

4.  解压 ZIP 文件。

5.  在解压后的目录中，找到手柄固件文件，例如:

        8BitDo_PCE_Fw_V405/Controller/PCE_24G_GamePad_V4.05.dat

6.  将手柄固件文件（例如 PCE_24G_GamePad_V4.05.dat） 复制到手柄 U
    盘的根目录。

7.  等待几分钟，让更新完成。

8.  在操作系统中安全弹出该 U 盘。

9.  断开 USB 线。

10. 在未连接 USB 的情况下，按住 HOME 键约 3 秒，让手柄完全退出升级模式 /
    关机。

11. 如有需要，再正常开机。

4. 安装 Analogue 固件（供 Analogue 主机使用）

本节说明如何安装或重新安装 Analogue 专用固件，以便直接用于 Analogue
系统（例如 Analogue Duo）。

1.  将手柄置于固件更新模式（见第 2 节）。

2.  在电脑上打开网页浏览器并访问:

        https://support.8bitdo.com/analogue/Dock/

3.  下载此手柄对应的 Analogue 固件包，例如:

        PCE_Fw_V5_01_For_Analogue.zip

    如有需要，可使用直链:

        https://download.8bitdo.com/Firmware/analogue/Dock/2.4g/PCE_Fw_V5_01_For_Analogue.zip

4.  解压 ZIP 文件。

5.  在解压后的目录中，找到固件文件，例如:

        PCE_Fw_V5_01_For_Analogue/PCE_Fw_V5_01_For_Analogue.dat

6.  将 Analogue 固件文件（例如 PCE_Fw_V5_01_For_Analogue.dat）
    复制到手柄 U 盘的根目录。

7.  等待几分钟，让更新完成。

8.  在操作系统中安全弹出该 U 盘。

9.  断开 USB 线。

10. 按住 HOME 键约 3 秒，直到所有 LED 熄灭。

11. 升级完成。

安装 Analogue 固件后，手柄将直接与 Analogue 主机的 2.4G 系统配对，
不会使用随附的 2.4G USB 接收器。

5. 将手柄与 Analogue Duo / Analogue Dock 配对

当手柄运行 Analogue 固件时，请使用以下步骤将其与 Analogue 无线系统配对：

1.  按 HOME 键开启手柄。
2.  按住 SELECT 键约 3 秒。
    -   蓝灯会开始快速闪烁。
3.  按下 Analogue Dock / Analogue Duo 上的配对按钮。
4.  配对成功后，手柄的蓝灯会常亮。
5.  首次成功配对后，下次通常会自动重新连接。

6. 让 USB 接收器进入固件更新模式

2.4G USB 接收器也有自己的固件，并且可以更新。

重要说明：

-   只有当手柄运行原厂固件并且正在与接收器通信时，才能让接收器进入更新模式。
-   使用 Analogue
    固件时，不会使用接收器，因此无法通过手柄触发接收器的更新模式。

要让 USB 接收器进入固件更新模式：

1.  确保手柄正在使用原厂固件，并且能够连接到接收器。

2.  将 2.4G USB 接收器插入电脑。

3.  按 HOME 键打开手柄。

    -   等待手柄与接收器建立连接（接收器指示灯应为常亮，而不仅仅是闪烁）。

4.  现在同时按住手柄上的以下三个按键:

        SELECT + RUN + HOME

5.  持续按住这三个按键，直到电脑上出现一个新的 USB U 盘。

    -   这个新出现的盘就是处于固件更新模式的 USB 接收器。

接收器固件文件位置（原厂 v4.05 包）：

-   解压原厂固件 ZIP（8BitDo_PCE_Fw_V405.zip）后， 接收器固件文件位于:

        8BitDo_PCE_Fw_V405/Receiver/PCE_24G_RR_V4.05.dat

6.  打开新出现的 U 盘（接收器）。

7.  将接收器固件文件:

        PCE_24G_RR_V4.05.dat

    复制到接收器 U 盘的根目录。

8.  等待几分钟，让更新完成。

9.  在操作系统中安全弹出该 U 盘。

10. 如有需要，拔下 USB 接收器后再重新插入。

完成后，USB 接收器就会运行更新后的固件。

7. 将手柄重新与 USB 接收器配对（在使用 Analogue 固件之后）

每当你从 Analogue 固件切回原厂固件时，都必须重新将手柄与其 USB
接收器配对。 否则，它们将无法进行无线连接。

将手柄与 USB 接收器配对的方法如下：

1.  将 2.4G USB 接收器插入你的 PC 或主机。
    -   接收器的蓝灯会闪烁。
2.  按 HOME 键打开手柄。
3.  按住 SELECT 键约 3 秒。
    -   手柄的蓝灯会开始快速闪烁。
4.  将手柄靠近接收器。
5.  配对成功后，手柄和接收器上的蓝灯都会保持常亮（稳定蓝灯）。

完成此步骤后，手柄与接收器就会在原厂固件下同步。

8. 恢复 / 解砖说明（实践观察）

这些说明基于固件恢复过程中观察到的真实恢复行为。

1.  如果手柄仍然能够进入固件更新模式，并且会挂载成一个 USB U 盘，
    那么引导程序很可能依然完好。
2.  复制完固件文件后，一定要先在操作系统中安全弹出手柄 U 盘，断开 USB
    线， 然后再在未连接 USB 电源的情况下按住 HOME 约 3 秒。
3.  在一次恢复案例中，从 Windows 刷写可以正常成功，而从 Linux 刷写后，
    即使已经正确同步并卸载，手柄仍然没有响应。因此，对于这个特定手柄，
    在固件刷写失败后的恢复场景下，Windows 是更安全的选择。
4.  如果手柄在更改固件后看起来像“死机”了一样，先让它充电更久一些，
    再判断它是否真的变砖。电量过低可能会误导诊断。
5.  在一次固件切换失败的案例中，正常的手柄更新组合键
    （SELECT + HOME）已经失效。然而，按住 SELECT + RUN + HOME
    几秒后，手柄重新进入了固件更新模式，蓝灯和绿灯同时闪烁。之后，
    将手柄连接到 Windows 机器并重新刷写固件，恢复成功。
6.  SELECT + RUN + HOME
    的官方用途，是在手柄运行原厂固件并且已连接接收器时，
    让接收器进入固件更新模式。然而，在上面描述的恢复案例中，
    这个组合键同样让手柄本体重新回到了固件更新模式。这个现象应被视为一种实践中的恢复观察，
    而不是官方记录的手柄恢复方法。

9. 在原厂固件与 Analogue 固件之间切换（总结）

-   如果你想让手柄直接与 Analogue 主机配合使用（不使用 USB 接收器）：
    -   安装 Analogue 专用固件（见第 4 节）。
    -   按第 5 节中的步骤，将其与 Analogue Dock / Duo 配对。
-   如果你想让手柄与随附的 2.4G USB 接收器配合使用：
    -   安装原厂 PCE 2.4G 固件（见第 3 节）。
    -   可选地更新 USB 接收器固件（见第 6 节）。
    -   然后按第 7 节中的步骤，重新将手柄与接收器配对。

请始终记住：

-   Analogue 固件 = 直接连接 Analogue 主机（不使用接收器）。
-   原厂固件 = 使用 USB 2.4G 接收器，并且必须与之配对。

Notas de firmware do controle 8BitDo PCE 2.4G

Este controle suporta DOIS tipos diferentes de firmware:

1)  Firmware padrão 8BitDo PCE 2.4G (“stock”)
2)  Firmware especial Analogue para consoles Analogue (por exemplo,
    Analogue Duo)

Leia isto se você for mudar o firmware algum dia.

1. Tipos de firmware

A)  Firmware stock do PCE 2.4G

-   Funciona com o receptor USB 2.4G incluído.
-   A comunicação sem fio é: Controle <-> Receptor USB.
-   Depois de gravar o firmware stock, você deve parear novamente o
    controle com o receptor USB (veja a seção 7).

B)  Firmware Analogue

-   Projetado para sistemas Analogue (como o Analogue Duo).
-   O controle se conecta diretamente ao rádio 2.4G do console Analogue.
-   Quando o firmware Analogue está em uso, o receptor USB 2.4G incluído
    NÃO é utilizado.
-   Se você depois voltar para o firmware stock, o controle deixará de
    se comunicar diretamente com o console Analogue e precisará ser
    pareado novamente com o receptor USB.

2. Entrando no modo de atualização de firmware (controle)

Use este procedimento sempre que quiser trocar o firmware (stock ou
Analogue):

1.  Certifique-se de que o controle esteja DESLIGADO.
2.  Pressione e SEGURE o botão SELECT.
3.  Enquanto segura SELECT, pressione rapidamente o botão HOME uma vez e
    então solte IMEDIATAMENTE os DOIS botões.
4.  Verifique se os LEDs azul e verde estão piscando ao mesmo tempo (em
    sincronia).
    -   Azul e verde piscando juntos = modo de atualização de firmware.
5.  Conecte o controle a um computador com um cabo USB.
6.  Uma nova unidade flash USB aparecerá (este é o armazenamento interno
    do controle).

Agora você pode copiar o arquivo de firmware apropriado para essa
unidade flash.

3. Instalando o firmware stock (PCE 2.4G padrão)

Esta seção descreve como instalar ou reinstalar o firmware stock padrão.

1.  Coloque o controle no modo de atualização de firmware (veja a seção
    2).

2.  No seu computador, abra um navegador web e vá para:

        https://support.8bitdo.com/

3.  Baixe o pacote de firmware stock do PCE 2.4G, por exemplo:

        8BitDo_PCE_Fw_V405.zip

    Link direto, se necessário:

        https://download.8bitdo.com/Firmware/Controller/PCE-2.4g/8BitDo_PCE_Fw_V405.zip

4.  Extraia o arquivo ZIP.

5.  Dentro da pasta extraída, localize o arquivo de firmware do
    controle, por exemplo:

        8BitDo_PCE_Fw_V405/Controller/PCE_24G_GamePad_V4.05.dat

6.  Copie o arquivo de firmware do controle (por exemplo,
    PCE_24G_GamePad_V4.05.dat) para a raiz da unidade flash do controle.

7.  Aguarde alguns minutos para que a atualização seja concluída.

8.  Ejete com segurança a unidade flash pelo sistema operacional.

9.  Desconecte o cabo USB.

10. Fora do USB, segure o botão HOME por cerca de 3 segundos para que o
    controle saia totalmente do modo de atualização / desligue.

11. Ligue-o normalmente se desejar.

4. Instalando o firmware Analogue (para consoles Analogue)

Esta seção descreve como instalar ou reinstalar o firmware específico da
Analogue para uso direto com sistemas Analogue (como o Analogue Duo).

1.  Coloque o controle no modo de atualização de firmware (veja a seção
    2).

2.  No seu computador, abra um navegador web e vá para:

        https://support.8bitdo.com/analogue/Dock/

3.  Baixe o pacote de firmware Analogue para este controle, por exemplo:

        PCE_Fw_V5_01_For_Analogue.zip

    Link direto, se necessário:

        https://download.8bitdo.com/Firmware/analogue/Dock/2.4g/PCE_Fw_V5_01_For_Analogue.zip

4.  Extraia o arquivo ZIP.

5.  Dentro da pasta extraída, localize o arquivo de firmware do
    controle, por exemplo:

        PCE_Fw_V5_01_For_Analogue/PCE_Fw_V5_01_For_Analogue.dat

6.  Copie o arquivo de firmware Analogue (por exemplo,
    PCE_Fw_V5_01_For_Analogue.dat) para a raiz da unidade flash do
    controle.

7.  Aguarde alguns minutos para que a atualização seja concluída.

8.  Ejete com segurança a unidade flash pelo sistema operacional.

9.  Desconecte o cabo USB.

10. Segure o botão HOME por cerca de 3 segundos até que todos os LEDs se
    apaguem.

11. Atualização concluída.

Quando o firmware Analogue está instalado, o controle fará pareamento
diretamente com o sistema 2.4G do console Analogue, e o receptor USB
2.4G incluído não será utilizado.

5. Pareando o controle com Analogue Duo / Analogue Dock

Quando o controle estiver executando o firmware Analogue, use este
procedimento para pareá-lo com o sistema sem fio Analogue:

1.  Pressione o botão HOME para ligar o controle.
2.  Pressione e SEGURE o botão SELECT por cerca de 3 segundos.
    -   O LED azul começará a piscar rapidamente.
3.  Pressione o botão de pareamento no Analogue Dock / Analogue Duo.
4.  Quando o pareamento for bem-sucedido, o LED azul do controle ficará
    aceso de forma contínua.
5.  Após o primeiro pareamento bem-sucedido, o controle deverá se
    reconectar automaticamente na próxima vez.

6. Colocando o receptor USB em modo de atualização de firmware

O receptor USB 2.4G também possui seu próprio firmware e pode ser
atualizado.

Importante:

-   O receptor só pode ser colocado em modo de atualização enquanto o
    controle estiver executando firmware STOCK e se comunicando com o
    receptor.
-   Com o firmware Analogue, o receptor não é utilizado, então o modo de
    atualização dele não pode ser acionado a partir do controle.

Para colocar o receptor USB em modo de atualização de firmware:

1.  Certifique-se de que o controle esteja usando firmware stock e
    consiga se conectar ao receptor.

2.  Conecte o receptor USB 2.4G ao seu computador.

3.  Ligue o controle pressionando o botão HOME.

    -   Aguarde até que o controle e o receptor estejam conectados (o
        LED do receptor deve ficar aceso de forma estável, e não apenas
        piscando).

4.  Agora pressione e SEGURE os três botões a seguir no controle ao
    mesmo tempo:

        SELECT + RUN + HOME

5.  Continue segurando esses três botões até que uma NOVA unidade flash
    USB apareça no computador.

    -   Essa nova unidade é o receptor USB em modo de atualização de
        firmware.

Localização do arquivo de firmware do receptor (pacote stock v4.05):

-   Após extrair o ZIP do firmware stock (8BitDo_PCE_Fw_V405.zip), o
    arquivo de firmware do receptor está aqui:

        8BitDo_PCE_Fw_V405/Receiver/PCE_24G_RR_V4.05.dat

6.  Abra a nova unidade flash que apareceu (o receptor).

7.  Copie o arquivo de firmware do receptor:

        PCE_24G_RR_V4.05.dat

    para a raiz da unidade flash do receptor.

8.  Aguarde alguns minutos para que a atualização seja concluída.

9.  Ejete com segurança a unidade flash pelo sistema operacional.

10. Desconecte o receptor USB e conecte-o novamente, se necessário.

Depois disso, o receptor USB estará executando o firmware atualizado.

7. Pareando novamente o controle com o receptor USB (após usar firmware Analogue)

Sempre que você trocar do firmware Analogue de volta para o firmware
stock, você DEVE parear novamente o controle com o seu receptor USB.
Caso contrário, eles não se conectarão sem fio.

Para parear o controle com o receptor USB:

1.  Conecte o receptor USB 2.4G ao seu PC ou console.
    -   O LED azul do receptor piscará.
2.  Ligue o controle com o botão HOME.
3.  Pressione e SEGURE o botão SELECT por cerca de 3 segundos.
    -   O LED azul do controle começará a piscar rapidamente.
4.  Mantenha o controle próximo ao receptor.
5.  Quando o pareamento for bem-sucedido, os LEDs azuis tanto do
    controle quanto do receptor ficarão acesos de forma contínua.

Depois desta etapa, o controle e o receptor ficarão sincronizados no
firmware stock.

8. Notas de recuperação / desbrick (observações práticas)

Estas notas são baseadas em comportamento real de recuperação observado
durante a recuperação de firmware.

1.  Se o controle ainda entra no modo de atualização de firmware e monta
    como uma unidade flash USB, o bootloader provavelmente ainda está
    funcional.
2.  Depois de copiar o arquivo de firmware, sempre ejete com segurança a
    unidade flash do controle, desconecte o cabo USB, e só então segure
    HOME por cerca de 3 segundos fora da alimentação USB.
3.  Em um caso de recuperação, gravar a partir do Windows funcionou
    corretamente, enquanto gravar a partir do Linux deixou o controle
    sem resposta mesmo após sync e desmontagem correta. Por causa disso,
    o Windows é a escolha mais segura para este controle específico ao
    recuperar de uma troca de firmware malsucedida.
4.  Se o controle parecer morto após uma troca de firmware, deixe-o
    carregando por mais tempo antes de concluir que ele foi brickado.
    Uma bateria muito baixa pode tornar o diagnóstico enganoso.
5.  Em um caso de falha na troca de firmware, a combinação normal de
    atualização do controle (SELECT + HOME) deixou de funcionar. Porém,
    segurar SELECT + RUN + HOME por alguns segundos fez o controle
    voltar a entrar no modo de atualização de firmware, com os LEDs azul
    e verde piscando juntos. Depois disso, conectar o controle a uma
    máquina Windows e gravar novamente o firmware funcionou.
6.  SELECT + RUN + HOME é oficialmente destinado a colocar o receptor em
    modo de atualização de firmware quando o controle está executando
    firmware stock e está conectado ao receptor. No entanto, no caso de
    recuperação descrito acima, essa mesma combinação também permitiu
    que o próprio controle voltasse ao modo de atualização de firmware.
    Isso deve ser tratado como uma observação prática de recuperação, e
    não como um método oficialmente documentado de recuperação do
    controle.

9. Alternando entre firmware stock e Analogue (resumo)

-   Para usar o controle diretamente com um console Analogue (sem
    receptor USB):
    -   Instale o firmware específico da Analogue (veja a seção 4).
    -   Faça o pareamento com o Analogue Dock / Duo usando os passos da
        seção 5.
-   Para usar o controle com o receptor USB 2.4G incluído:
    -   Instale o firmware stock do PCE 2.4G (veja a seção 3).
    -   Opcionalmente atualize o firmware do receptor USB (veja a seção
        6).
    -   Depois, pareie novamente o controle e o receptor usando os
        passos da seção 7.

Lembre-se sempre:

-   Firmware Analogue = conexão direta com o console Analogue (sem
    receptor).
-   Firmware stock = usa o receptor USB 2.4G e precisa ser pareado com
    ele.

8BitDo PCE 2.4G Gamepad — заметки по прошивке
============================================

Этот контроллер поддерживает ДВА разных типа прошивки:

1) Стандартная прошивка 8BitDo PCE 2.4G (“stock”)
2) Специальная прошивка Analogue для консолей Analogue (например, Analogue Duo)

Пожалуйста, прочитайте это, если вы собираетесь менять прошивку.


1. Типы прошивки
----------------

A) Stock-прошивка PCE 2.4G

- Работает с комплектным USB-приёмником 2.4G.
- Беспроводная связь выглядит так: Контроллер <-> USB-приёмник.
- После прошивки stock-версии вы должны заново выполнить сопряжение контроллера с USB-приёмником (см. раздел 7).

B) Прошивка Analogue

- Предназначена для систем Analogue (например, Analogue Duo).
- Контроллер подключается напрямую к 2.4G-радиомодулю консоли Analogue.
- При использовании прошивки Analogue комплектный USB-приёмник 2.4G НЕ используется.
- Если позже вы вернётесь на stock-прошивку, контроллер больше не будет напрямую работать с консолью Analogue и его нужно будет заново сопрячь с USB-приёмником.


2. Вход в режим обновления прошивки (контроллер)
------------------------------------------------

Используйте эту процедуру всякий раз, когда хотите сменить прошивку (stock или Analogue):

1. Убедитесь, что контроллер ВЫКЛЮЧЕН.
2. Нажмите и УДЕРЖИВАЙТЕ кнопку ``SELECT``.
3. Удерживая ``SELECT``, кратко нажмите кнопку ``HOME`` один раз и сразу отпустите ОБЕ кнопки.
4. Убедитесь, что синий и зелёный светодиоды мигают одновременно (синхронно).

   - Синий и зелёный мигают вместе = режим обновления прошивки.

5. Подключите контроллер к компьютеру с помощью USB-кабеля.
6. Появится новый USB-накопитель (это внутренняя память контроллера).

Теперь вы можете скопировать нужный файл прошивки на этот накопитель.


3. Установка stock-прошивки (стандартная PCE 2.4G)
--------------------------------------------------

В этом разделе описано, как установить или переустановить стандартную stock-прошивку.

1. Переведите контроллер в режим обновления прошивки (см. раздел 2).
2. На компьютере откройте веб-браузер и перейдите по адресу::

      https://support.8bitdo.com/

3. Скачайте пакет stock-прошивки для PCE 2.4G, например::

      8BitDo_PCE_Fw_V405.zip

   Прямая ссылка, если понадобится::

      https://download.8bitdo.com/Firmware/Controller/PCE-2.4g/8BitDo_PCE_Fw_V405.zip

4. Распакуйте ZIP-файл.
5. В распакованной папке найдите файл прошивки контроллера, например::

      8BitDo_PCE_Fw_V405/Controller/PCE_24G_GamePad_V4.05.dat

6. Скопируйте файл прошивки контроллера (например, ``PCE_24G_GamePad_V4.05.dat``)
   в корень USB-накопителя контроллера.
7. Подождите пару минут, чтобы обновление завершилось.
8. Безопасно извлеките накопитель средствами операционной системы.
9. Отключите USB-кабель.
10. Без USB удерживайте кнопку ``HOME`` около 3 секунд, чтобы контроллер полностью вышел из режима обновления / выключился.
11. При желании включите его обычным образом.


4. Установка прошивки Analogue (для консолей Analogue)
------------------------------------------------------

В этом разделе описано, как установить или переустановить специальную прошивку
Analogue для прямого использования с системами Analogue (например, Analogue Duo).

1. Переведите контроллер в режим обновления прошивки (см. раздел 2).
2. На компьютере откройте веб-браузер и перейдите по адресу::

      https://support.8bitdo.com/analogue/Dock/

3. Скачайте пакет прошивки Analogue для этого контроллера, например::

      PCE_Fw_V5_01_For_Analogue.zip

   Прямая ссылка, если понадобится::

      https://download.8bitdo.com/Firmware/analogue/Dock/2.4g/PCE_Fw_V5_01_For_Analogue.zip

4. Распакуйте ZIP-файл.
5. В распакованной папке найдите файл прошивки контроллера, например::

      PCE_Fw_V5_01_For_Analogue/PCE_Fw_V5_01_For_Analogue.dat

6. Скопируйте файл прошивки Analogue (например, ``PCE_Fw_V5_01_For_Analogue.dat``)
   в корень USB-накопителя контроллера.
7. Подождите пару минут, чтобы обновление завершилось.
8. Безопасно извлеките накопитель средствами операционной системы.
9. Отключите USB-кабель.
10. Удерживайте кнопку ``HOME`` около 3 секунд, пока все светодиоды не погаснут.
11. Обновление завершено.

Когда установлена прошивка Analogue, контроллер будет сопрягаться напрямую с
2.4G-системой консоли Analogue, а комплектный USB-приёмник 2.4G использоваться не будет.


5. Сопряжение контроллера с Analogue Duo / Analogue Dock
--------------------------------------------------------

Когда на контроллере используется прошивка Analogue, используйте эту процедуру для
сопряжения с беспроводной системой Analogue:

1. Нажмите кнопку ``HOME``, чтобы включить контроллер.
2. Нажмите и УДЕРЖИВАЙТЕ кнопку ``SELECT`` около 3 секунд.

   - Синий светодиод начнёт быстро мигать.

3. Нажмите кнопку сопряжения на Analogue Dock / Analogue Duo.
4. Когда сопряжение завершится успешно, синий светодиод контроллера будет гореть постоянно.
5. После первого успешного сопряжения контроллер должен автоматически переподключаться в следующий раз.


6. Перевод USB-приёмника в режим обновления прошивки
----------------------------------------------------

USB-приёмник 2.4G также имеет собственную прошивку и может обновляться.

Важно:

- Приёмник можно перевести в режим обновления только тогда, когда контроллер использует
  прошивку STOCK и обменивается данными с приёмником.
- При прошивке Analogue приёмник не используется, поэтому его режим обновления нельзя
  запустить с контроллера.

Чтобы перевести USB-приёмник в режим обновления прошивки:

1. Убедитесь, что контроллер использует stock-прошивку и может подключиться к приёмнику.
2. Подключите USB-приёмник 2.4G к компьютеру.
3. Включите контроллер, нажав кнопку ``HOME``.

   - Подождите, пока контроллер и приёмник соединятся (светодиод приёмника должен гореть постоянно, а не просто мигать).

4. Теперь одновременно нажмите и УДЕРЖИВАЙТЕ на контроллере следующие три кнопки::

      SELECT + RUN + HOME

5. Продолжайте удерживать эти три кнопки, пока на компьютере не появится НОВЫЙ USB-накопитель.

   - Этот новый накопитель — USB-приёмник в режиме обновления прошивки.

Расположение файла прошивки приёмника (пакет stock v4.05):

- После распаковки ZIP-архива stock-прошивки (``8BitDo_PCE_Fw_V405.zip``)
  файл прошивки приёмника находится здесь::

      8BitDo_PCE_Fw_V405/Receiver/PCE_24G_RR_V4.05.dat

6. Откройте появившийся новый накопитель (приёмник).
7. Скопируйте файл прошивки приёмника::

      PCE_24G_RR_V4.05.dat

   в корень накопителя приёмника.
8. Подождите пару минут, чтобы обновление завершилось.
9. Безопасно извлеките накопитель средствами операционной системы.
10. При необходимости отключите USB-приёмник и подключите его снова.

После этого USB-приёмник будет работать на обновлённой прошивке.


7. Повторное сопряжение контроллера с USB-приёмником (после использования прошивки Analogue)
---------------------------------------------------------------------------------------------

Каждый раз, когда вы переходите с прошивки Analogue обратно на stock-прошивку,
вы ОБЯЗАНЫ заново сопрячь контроллер с его USB-приёмником. Иначе беспроводное
подключение работать не будет.

Чтобы сопрячь контроллер с USB-приёмником:

1. Подключите USB-приёмник 2.4G к вашему ПК или консоли.

   - Синий светодиод приёмника начнёт мигать.

2. Включите контроллер кнопкой ``HOME``.
3. Нажмите и УДЕРЖИВАЙТЕ кнопку ``SELECT`` около 3 секунд.

   - Синий светодиод контроллера начнёт быстро мигать.

4. Держите контроллер рядом с приёмником.
5. Когда сопряжение завершится успешно, синие светодиоды и на контроллере, и на приёмнике
   будут гореть постоянно.

После этого контроллер и приёмник будут синхронизированы на stock-прошивке.


8. Заметки по восстановлению / разкирпичиванию (практические наблюдения)
------------------------------------------------------------------------

Эти заметки основаны на реальном поведении, наблюдавшемся при восстановлении прошивки.

1. Если контроллер всё ещё входит в режим обновления прошивки и монтируется как USB-накопитель,
   скорее всего, загрузчик всё ещё работает.

2. После копирования файла прошивки всегда безопасно извлекайте накопитель контроллера,
   отключайте USB-кабель, и только потом удерживайте ``HOME`` около 3 секунд без питания по USB.

3. В одном случае восстановления прошивка из Windows сработала правильно, а прошивка из Linux
   оставила контроллер без отклика даже после sync и корректного размонтирования. Поэтому для
   этого конкретного контроллера Windows — более безопасный вариант при восстановлении после
   неудачной смены прошивки.

4. Если после смены прошивки контроллер кажется мёртвым, дайте ему подольше зарядиться,
   прежде чем считать его окончательно “окирпиченным”. Очень низкий заряд батареи может вводить в заблуждение.

5. В одном случае неудачной смены прошивки обычная комбинация обновления контроллера
   (``SELECT + HOME``) больше не работала. Однако удерживание ``SELECT + RUN + HOME``
   в течение нескольких секунд снова перевело контроллер в режим обновления прошивки,
   при этом синий и зелёный светодиоды мигали вместе. После этого подключение контроллера
   к машине с Windows и повторная прошивка оказались успешными.

6. Официально комбинация ``SELECT + RUN + HOME`` предназначена для перевода приёмника
   в режим обновления прошивки, когда контроллер использует stock-прошивку и подключён к приёмнику.
   Однако в описанном выше случае восстановления эта же комбинация также позволила самому контроллеру
   вернуться в режим обновления прошивки. Это следует считать практическим наблюдением по восстановлению,
   а не официально задокументированным методом восстановления контроллера.


9. Переключение между stock- и Analogue-прошивкой (кратко)
----------------------------------------------------------

- Чтобы использовать контроллер напрямую с консолью Analogue (без USB-приёмника):

  - Установите специальную прошивку Analogue (см. раздел 4).
  - Выполните сопряжение с Analogue Dock / Duo по шагам из раздела 5.

- Чтобы использовать контроллер с комплектным USB-приёмником 2.4G:

  - Установите stock-прошивку PCE 2.4G (см. раздел 3).
  - При желании обновите прошивку USB-приёмника (см. раздел 6).
  - Затем заново сопрягите контроллер и приёмник по шагам из раздела 7.

Всегда помните:

- Прошивка Analogue = прямое подключение к консоли Analogue (без приёмника).
- Stock-прошивка = использует USB-приёмник 2.4G и должна быть с ним сопряжена.

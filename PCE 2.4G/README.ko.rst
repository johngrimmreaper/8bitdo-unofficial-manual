8BitDo PCE 2.4G 게임패드 — 펌웨어 노트
======================================

이 컨트롤러는 두 가지 서로 다른 펌웨어 유형을 지원합니다.

1) 표준 8BitDo PCE 2.4G 펌웨어 (“stock”)
2) Analogue 콘솔용 특수 Analogue 펌웨어 (예: Analogue Duo)

펌웨어를 변경할 경우 이 문서를 먼저 읽어 주세요.


1. 펌웨어 유형
--------------

A) Stock PCE 2.4G 펌웨어

- 동봉된 2.4G USB 리시버와 함께 동작합니다.
- 무선 통신 방식은 다음과 같습니다: 컨트롤러 <-> USB 리시버.
- Stock 펌웨어를 플래시한 후에는 컨트롤러를 USB 리시버와 다시 페어링해야 합니다 (7절 참조).

B) Analogue 펌웨어

- Analogue 시스템(예: Analogue Duo)을 위해 설계되었습니다.
- 컨트롤러는 Analogue 콘솔의 2.4G 무선과 직접 연결됩니다.
- Analogue 펌웨어를 사용할 때는 동봉된 2.4G USB 리시버를 사용하지 않습니다.
- 나중에 Stock 펌웨어로 다시 돌아가면, 컨트롤러는 더 이상 Analogue 콘솔과 직접 통신하지 않으며 USB 리시버와 다시 페어링해야 합니다.


2. 펌웨어 업데이트 모드로 들어가기 (컨트롤러)
--------------------------------------------

펌웨어(Stock 또는 Analogue)를 변경하려면 항상 다음 절차를 사용하십시오.

1. 컨트롤러 전원이 꺼져 있는지 확인합니다.
2. ``SELECT`` 버튼을 누른 채 유지합니다.
3. ``SELECT`` 를 누른 상태에서 ``HOME`` 버튼을 한 번 짧게 누른 뒤, 두 버튼을 즉시 모두 놓습니다.
4. 파란색 LED 와 초록색 LED 가 동시에(동기화되어) 깜빡이는지 확인합니다.

   - 파란색과 초록색이 동시에 깜빡임 = 펌웨어 업데이트 모드.

5. USB 케이블로 컨트롤러를 컴퓨터에 연결합니다.
6. 새 USB 플래시 드라이브가 나타납니다 (이것은 컨트롤러의 내부 저장소입니다).

이제 적절한 펌웨어 파일을 이 플래시 드라이브에 복사할 수 있습니다.


3. Stock 펌웨어 설치하기 (표준 PCE 2.4G)
----------------------------------------

이 절에서는 표준 Stock 펌웨어를 설치하거나 다시 설치하는 방법을 설명합니다.

1. 컨트롤러를 펌웨어 업데이트 모드로 전환합니다 (2절 참조).
2. 컴퓨터에서 웹 브라우저를 열고 다음으로 이동합니다::

      https://support.8bitdo.com/

3. PCE 2.4G Stock 펌웨어 패키지를 다운로드합니다. 예::

      8BitDo_PCE_Fw_V405.zip

   필요하면 직접 링크::

      https://download.8bitdo.com/Firmware/Controller/PCE-2.4g/8BitDo_PCE_Fw_V405.zip

4. ZIP 파일을 압축 해제합니다.
5. 압축 해제한 폴더 안에서 컨트롤러 펌웨어 파일을 찾습니다. 예::

      8BitDo_PCE_Fw_V405/Controller/PCE_24G_GamePad_V4.05.dat

6. 컨트롤러 펌웨어 파일(예: ``PCE_24G_GamePad_V4.05.dat``)
   을 컨트롤러 플래시 드라이브의 루트에 복사합니다.
7. 업데이트가 완료될 때까지 몇 분 정도 기다립니다.
8. 운영체제에서 플래시 드라이브를 안전하게 제거합니다.
9. USB 케이블을 분리합니다.
10. USB 에서 분리된 상태로 ``HOME`` 버튼을 약 3초 동안 눌러 컨트롤러가 업데이트 모드에서 완전히 빠져나오거나 전원이 꺼지도록 합니다.
11. 필요하면 정상적으로 다시 켭니다.


4. Analogue 펌웨어 설치하기 (Analogue 콘솔용)
--------------------------------------------

이 절에서는 Analogue 시스템(예: Analogue Duo)에서 직접 사용하기 위한
Analogue 전용 펌웨어를 설치하거나 다시 설치하는 방법을 설명합니다.

1. 컨트롤러를 펌웨어 업데이트 모드로 전환합니다 (2절 참조).
2. 컴퓨터에서 웹 브라우저를 열고 다음으로 이동합니다::

      https://support.8bitdo.com/analogue/Dock/

3. 이 컨트롤러용 Analogue 펌웨어 패키지를 다운로드합니다. 예::

      PCE_Fw_V5_01_For_Analogue.zip

   필요하면 직접 링크::

      https://download.8bitdo.com/Firmware/analogue/Dock/2.4g/PCE_Fw_V5_01_For_Analogue.zip

4. ZIP 파일을 압축 해제합니다.
5. 압축 해제한 폴더 안에서 컨트롤러 펌웨어 파일을 찾습니다. 예::

      PCE_Fw_V5_01_For_Analogue/PCE_Fw_V5_01_For_Analogue.dat

6. Analogue 펌웨어 파일(예: ``PCE_Fw_V5_01_For_Analogue.dat``)
   을 컨트롤러 플래시 드라이브의 루트에 복사합니다.
7. 업데이트가 완료될 때까지 몇 분 정도 기다립니다.
8. 운영체제에서 플래시 드라이브를 안전하게 제거합니다.
9. USB 케이블을 분리합니다.
10. 모든 LED 가 꺼질 때까지 ``HOME`` 버튼을 약 3초 동안 누르고 있습니다.
11. 업그레이드 완료.

Analogue 펌웨어가 설치되면 컨트롤러는 Analogue 콘솔의 2.4G 시스템과 직접 페어링되며,
동봉된 2.4G USB 리시버는 사용되지 않습니다.


5. 컨트롤러를 Analogue Duo / Analogue Dock 과 페어링하기
-------------------------------------------------------

컨트롤러가 Analogue 펌웨어를 실행 중일 때, Analogue 무선 시스템과 페어링하려면
다음 절차를 사용하십시오.

1. ``HOME`` 버튼을 눌러 컨트롤러 전원을 켭니다.
2. ``SELECT`` 버튼을 약 3초 동안 누르고 있습니다.

   - 파란색 LED 가 빠르게 깜빡이기 시작합니다.

3. Analogue Dock / Analogue Duo 의 페어링 버튼을 누릅니다.
4. 페어링이 성공하면 컨트롤러의 파란색 LED 가 계속 켜진 상태로 유지됩니다.
5. 첫 페어링이 성공한 후에는 다음부터 자동으로 다시 연결되어야 합니다.


6. USB 리시버를 펌웨어 업데이트 모드로 넣기
------------------------------------------

2.4G USB 리시버에도 자체 펌웨어가 있으며 업데이트할 수 있습니다.

중요:

- 리시버는 컨트롤러가 STOCK 펌웨어를 실행 중이고 리시버와 통신하고 있을 때만 업데이트 모드로 넣을 수 있습니다.
- Analogue 펌웨어에서는 리시버를 사용하지 않으므로, 컨트롤러에서 리시버의 업데이트 모드를 트리거할 수 없습니다.

USB 리시버를 펌웨어 업데이트 모드로 넣으려면:

1. 컨트롤러가 Stock 펌웨어를 사용 중이며 리시버에 연결될 수 있는지 확인합니다.
2. 2.4G USB 리시버를 컴퓨터에 연결합니다。
3. ``HOME`` 버튼을 눌러 컨트롤러 전원을 켭니다.

   - 컨트롤러와 리시버가 연결될 때까지 기다립니다 (리시버 LED 는 단순 점멸이 아니라 계속 켜져 있어야 합니다).

4. 이제 컨트롤러에서 다음 세 버튼을 동시에 누르고 유지합니다::

      SELECT + RUN + HOME

5. 컴퓨터에 새로운 USB 플래시 드라이브가 나타날 때까지 이 세 버튼을 계속 누르고 있습니다.

   - 이 새 드라이브가 펌웨어 업데이트 모드의 USB 리시버입니다.

리시버 펌웨어 파일 위치 (Stock v4.05 패키지):

- Stock 펌웨어 ZIP (``8BitDo_PCE_Fw_V405.zip``)을 압축 해제한 후,
  리시버 펌웨어 파일은 다음 위치에 있습니다::

      8BitDo_PCE_Fw_V405/Receiver/PCE_24G_RR_V4.05.dat

6. 새로 나타난 플래시 드라이브(리시버)를 엽니다.
7. 리시버 펌웨어 파일::

      PCE_24G_RR_V4.05.dat

   을 리시버 플래시 드라이브의 루트에 복사합니다.
8. 업데이트가 완료될 때까지 몇 분 정도 기다립니다.
9. 운영체제에서 플래시 드라이브를 안전하게 제거합니다.
10. 필요하면 USB 리시버를 뽑았다가 다시 꽂습니다.

이제 USB 리시버는 업데이트된 펌웨어로 동작합니다.


7. 컨트롤러를 USB 리시버와 다시 페어링하기 (Analogue 펌웨어 사용 후)
------------------------------------------------------------------------

Analogue 펌웨어에서 다시 Stock 펌웨어로 전환할 때마다, 컨트롤러를 USB 리시버와
반드시 다시 페어링해야 합니다. 그렇지 않으면 무선으로 연결되지 않습니다.

컨트롤러를 USB 리시버와 페어링하려면:

1. 2.4G USB 리시버를 PC 또는 콘솔에 연결합니다.

   - 리시버의 파란색 LED 가 깜빡입니다.

2. ``HOME`` 버튼으로 컨트롤러 전원을 켭니다.
3. ``SELECT`` 버튼을 약 3초 동안 누르고 있습니다.

   - 컨트롤러의 파란색 LED 가 빠르게 깜빡이기 시작합니다.

4. 컨트롤러를 리시버 가까이에 둡니다.
5. 페어링이 성공하면 컨트롤러와 리시버 양쪽의 파란색 LED 가 계속 켜진 상태가 됩니다.

이 단계 후, 컨트롤러와 리시버는 Stock 펌웨어에서 동기화됩니다.


8. 복구 / 언브릭 노트 (실제 관찰)
--------------------------------

이 노트들은 펌웨어 복구 중 실제로 관찰된 동작에 기반합니다.

1. 컨트롤러가 여전히 펌웨어 업데이트 모드로 들어가고 USB 플래시 드라이브처럼 마운트된다면,
   부트로더는 아직 살아 있을 가능성이 큽니다.

2. 펌웨어 파일을 복사한 후에는 항상 컨트롤러 플래시 드라이브를 안전하게 제거하고,
   USB 케이블을 분리한 다음, USB 전원이 없는 상태에서만 ``HOME`` 을 약 3초 동안 누르십시오.

3. 한 복구 사례에서는 Windows 에서 플래시했을 때는 정상적으로 동작했지만, Linux 에서 플래시했을 때는
   sync 와 올바른 언마운트 후에도 컨트롤러가 응답하지 않았습니다. 따라서 이 특정 컨트롤러의 경우,
   실패한 펌웨어 변경 후 복구에는 Windows 가 더 안전한 선택입니다.

4. 펌웨어 변경 후 컨트롤러가 죽은 것처럼 보인다면, 완전히 벽돌이 되었다고 결론 내리기 전에
   조금 더 오래 충전해 보십시오. 배터리가 너무 부족하면 진단이 잘못될 수 있습니다.

5. 한 펌웨어 변경 실패 사례에서는 일반적인 업데이트 조합
   (``SELECT + HOME``)이 더 이상 동작하지 않았습니다. 그러나 ``SELECT + RUN + HOME`` 을
   몇 초 동안 누르고 있었더니, 파란색과 초록색 LED 가 함께 깜빡이며 컨트롤러가 다시
   펌웨어 업데이트 모드로 들어갔습니다. 그 후 Windows 컴퓨터에 연결하여 펌웨어를 다시 플래시하자
   복구에 성공했습니다.

6. 공식적으로 ``SELECT + RUN + HOME`` 은 컨트롤러가 Stock 펌웨어를 사용 중이고 리시버와 연결되어 있을 때,
   리시버를 펌웨어 업데이트 모드로 넣기 위한 조합입니다. 하지만 위에서 설명한 복구 사례에서는
   같은 조합이 컨트롤러 자체를 다시 펌웨어 업데이트 모드로 돌려놓는 데에도 사용되었습니다.
   이것은 실제 복구 관찰로 보아야 하며, 공식적으로 문서화된 컨트롤러 복구 방법으로 보아서는 안 됩니다.


9. Stock 과 Analogue 펌웨어 전환하기 (요약)
------------------------------------------

- 컨트롤러를 Analogue 콘솔과 직접 사용하려면 (USB 리시버 없이):

  - Analogue 전용 펌웨어를 설치합니다 (4절 참조).
  - 5절의 단계에 따라 Analogue Dock / Duo 와 페어링합니다.

- 컨트롤러를 동봉된 2.4G USB 리시버와 함께 사용하려면:

  - Stock PCE 2.4G 펌웨어를 설치합니다 (3절 참조).
  - 필요하면 USB 리시버 펌웨어를 업데이트합니다 (6절 참조).
  - 그 다음 7절의 단계에 따라 컨트롤러와 리시버를 다시 페어링합니다.

항상 기억하십시오:

- Analogue 펌웨어 = Analogue 콘솔과 직접 연결 (리시버 없음).
- Stock 펌웨어 = 2.4G USB 리시버를 사용하며, 리시버와 페어링되어야 합니다.

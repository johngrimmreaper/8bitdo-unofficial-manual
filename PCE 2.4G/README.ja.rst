8BitDo PCE 2.4G ゲームパッド — ファームウェアノート
==================================================

このコントローラーは、2種類の異なるファームウェアをサポートしています。

1) 標準の 8BitDo PCE 2.4G ファームウェア（“stock”）
2) Analogue コンソール向けの特別な Analogue ファームウェア（例: Analogue Duo）

ファームウェアを変更する場合は、まずこれを読んでください。


1. ファームウェアの種類
-----------------------

A) Stock PCE 2.4G ファームウェア

- 付属の 2.4G USB レシーバーと動作します。
- 無線通信は次のようになります: コントローラー <-> USB レシーバー。
- Stock ファームウェアを書き込んだ後は、コントローラーを USB レシーバーと再度ペアリングする必要があります（第7節を参照）。

B) Analogue ファームウェア

- Analogue システム（Analogue Duo など）向けに設計されています。
- コントローラーは Analogue コンソールの 2.4G 無線に直接接続します。
- Analogue ファームウェア使用時は、付属の 2.4G USB レシーバーは使用されません。
- 後で Stock ファームウェアに戻した場合、コントローラーは Analogue コンソールと直接通信しなくなり、USB レシーバーと再度ペアリングする必要があります。


2. ファームウェア更新モードに入る（コントローラー）
----------------------------------------------------

ファームウェア（Stock または Analogue）を変更したい場合は、必ず次の手順を使用してください。

1. コントローラーの電源が切れていることを確認します。
2. ``SELECT`` ボタンを押したままにします。
3. ``SELECT`` を押したまま、``HOME`` ボタンを1回短く押し、その後すぐに両方のボタンを離します。
4. 青色 LED と緑色 LED が同時に（同期して）点滅していることを確認します。

   - 青色と緑色が同時に点滅 = ファームウェア更新モード。

5. USB ケーブルでコントローラーをコンピューターに接続します。
6. 新しい USB フラッシュドライブが表示されます（これはコントローラー内部のストレージです）。

これで、適切なファームウェアファイルをこのフラッシュドライブにコピーできます。


3. Stock ファームウェアをインストールする（標準 PCE 2.4G）
------------------------------------------------------------

この節では、標準の Stock ファームウェアをインストールまたは再インストールする方法を説明します。

1. コントローラーをファームウェア更新モードにします（第2節を参照）。
2. コンピューターで Web ブラウザーを開き、次へアクセスします::

      https://support.8bitdo.com/

3. PCE 2.4G の Stock ファームウェアパッケージをダウンロードします。例::

      8BitDo_PCE_Fw_V405.zip

   必要であれば直リンク::

      https://download.8bitdo.com/Firmware/Controller/PCE-2.4g/8BitDo_PCE_Fw_V405.zip

4. ZIP ファイルを展開します。
5. 展開したフォルダー内で、コントローラーのファームウェアファイルを探します。例::

      8BitDo_PCE_Fw_V405/Controller/PCE_24G_GamePad_V4.05.dat

6. コントローラーのファームウェアファイル（例: ``PCE_24G_GamePad_V4.05.dat``）
   をコントローラーのフラッシュドライブのルートにコピーします。
7. 更新が完了するまで数分待ちます。
8. OS からフラッシュドライブを安全に取り外します。
9. USB ケーブルを抜きます。
10. USB から外した状態で、``HOME`` ボタンを約3秒間押し続け、コントローラーを完全に更新モードから抜けさせる / 電源を切ります。
11. 必要であれば通常通り電源を入れます。


4. Analogue ファームウェアをインストールする（Analogue コンソール向け）
--------------------------------------------------------------------------

この節では、Analogue システム（Analogue Duo など）で直接使用するための
Analogue 専用ファームウェアをインストールまたは再インストールする方法を説明します。

1. コントローラーをファームウェア更新モードにします（第2節を参照）。
2. コンピューターで Web ブラウザーを開き、次へアクセスします::

      https://support.8bitdo.com/analogue/Dock/

3. このコントローラー向けの Analogue ファームウェアパッケージをダウンロードします。例::

      PCE_Fw_V5_01_For_Analogue.zip

   必要であれば直リンク::

      https://download.8bitdo.com/Firmware/analogue/Dock/2.4g/PCE_Fw_V5_01_For_Analogue.zip

4. ZIP ファイルを展開します。
5. 展開したフォルダー内で、コントローラーのファームウェアファイルを探します。例::

      PCE_Fw_V5_01_For_Analogue/PCE_Fw_V5_01_For_Analogue.dat

6. Analogue ファームウェアファイル（例: ``PCE_Fw_V5_01_For_Analogue.dat``）
   をコントローラーのフラッシュドライブのルートにコピーします。
7. 更新が完了するまで数分待ちます。
8. OS からフラッシュドライブを安全に取り外します。
9. USB ケーブルを抜きます。
10. すべての LED が消えるまで ``HOME`` ボタンを約3秒間押し続けます。
11. 更新完了。

Analogue ファームウェアがインストールされると、コントローラーは Analogue
コンソールの 2.4G システムと直接ペアリングされ、付属の 2.4G USB レシーバーは使用されません。


5. コントローラーを Analogue Duo / Analogue Dock とペアリングする
--------------------------------------------------------------------

コントローラーが Analogue ファームウェアを実行している場合、Analogue の無線システムと
ペアリングするには次の手順を使用してください。

1. ``HOME`` ボタンを押してコントローラーの電源を入れます。
2. ``SELECT`` ボタンを約3秒間押し続けます。

   - 青色 LED が高速で点滅し始めます。

3. Analogue Dock / Analogue Duo のペアリングボタンを押します。
4. ペアリングに成功すると、コントローラーの青色 LED が点灯したままになります。
5. 最初のペアリングが成功した後は、次回から自動的に再接続されるはずです。


6. USB レシーバーをファームウェア更新モードにする
----------------------------------------------------

2.4G USB レシーバーにも独自のファームウェアがあり、更新できます。

重要:

- レシーバーを更新モードにできるのは、コントローラーが STOCK ファームウェアを実行し、
  レシーバーと通信しているときだけです。
- Analogue ファームウェアではレシーバーは使用されないため、コントローラーから
  レシーバーの更新モードを起動することはできません。

USB レシーバーをファームウェア更新モードにするには:

1. コントローラーが Stock ファームウェアを使用しており、レシーバーに接続できることを確認します。
2. 2.4G USB レシーバーをコンピューターに接続します。
3. ``HOME`` ボタンを押してコントローラーの電源を入れます。

   - コントローラーとレシーバーが接続されるまで待ちます（レシーバーの LED は点滅ではなく、点灯状態である必要があります）。

4. 次に、コントローラーで以下の3つのボタンを同時に押し続けます::

      SELECT + RUN + HOME

5. コンピューターに新しい USB フラッシュドライブが表示されるまで、この3つのボタンを押し続けます。

   - この新しいドライブが、ファームウェア更新モードに入った USB レシーバーです。

レシーバーのファームウェアファイルの場所（Stock v4.05 パッケージ）:

- Stock ファームウェア ZIP（``8BitDo_PCE_Fw_V405.zip``）を展開した後、
  レシーバーのファームウェアファイルは次の場所にあります::

      8BitDo_PCE_Fw_V405/Receiver/PCE_24G_RR_V4.05.dat

6. 新しく表示されたフラッシュドライブ（レシーバー）を開きます。
7. レシーバーのファームウェアファイル::

      PCE_24G_RR_V4.05.dat

   をレシーバーのフラッシュドライブのルートにコピーします。
8. 更新が完了するまで数分待ちます。
9. OS からフラッシュドライブを安全に取り外します。
10. 必要であれば USB レシーバーを抜き差しします。

これで USB レシーバーは更新後のファームウェアで動作します。


7. コントローラーを USB レシーバーと再ペアリングする（Analogue ファームウェア使用後）
----------------------------------------------------------------------------------------

Analogue ファームウェアから Stock ファームウェアに戻すたびに、コントローラーを
USB レシーバーと再度ペアリングしなければなりません。そうしないと無線接続できません。

コントローラーを USB レシーバーとペアリングするには:

1. 2.4G USB レシーバーを PC またはコンソールに接続します。

   - レシーバーの青色 LED が点滅します。

2. ``HOME`` ボタンでコントローラーの電源を入れます。
3. ``SELECT`` ボタンを約3秒間押し続けます。

   - コントローラーの青色 LED が高速で点滅し始めます。

4. コントローラーをレシーバーの近くに置きます。
5. ペアリングに成功すると、コントローラーとレシーバーの両方の青色 LED が点灯したままになります。

この手順の後、コントローラーとレシーバーは Stock ファームウェアで同期されます。


8. 復旧 / アンブリックに関するメモ（実地観察）
----------------------------------------------

これらのメモは、ファームウェア復旧中に観察された実際の挙動に基づいています。

1. コントローラーがまだファームウェア更新モードに入り、USB フラッシュドライブとして
   マウントされる場合、ブートローダーはまだ生きている可能性が高いです。

2. ファームウェアファイルをコピーした後は、必ずコントローラーのフラッシュドライブを安全に
   取り外し、USB ケーブルを抜いてから、USB 電源につながっていない状態で ``HOME`` を約3秒間押してください。

3. ある復旧事例では、Windows からの書き込みは正常に成功しましたが、Linux からの書き込みでは
   sync と正しいアンマウントの後でもコントローラーが応答しなくなりました。そのため、この特定の
   コントローラーでは、失敗したファームウェア変更からの復旧には Windows の方が安全です。

4. ファームウェア変更後にコントローラーが死んだように見える場合でも、完全に壊れたと判断する前に、
   もう少し長く充電してみてください。バッテリー残量が極端に少ないと診断を誤ることがあります。

5. あるファームウェア変更失敗事例では、通常の更新用キー操作
   （``SELECT + HOME``）が使えなくなっていました。しかし ``SELECT + RUN + HOME`` を
   数秒間押し続けると、青色と緑色 LED が同時に点滅し、コントローラーが再びファームウェア更新モードに入りました。
   その後、Windows マシンに接続してファームウェアを書き直すことで復旧に成功しました。

6. ``SELECT + RUN + HOME`` は公式には、コントローラーが Stock ファームウェアを使用し、
   レシーバーに接続しているときに、レシーバーをファームウェア更新モードに入れるための操作です。
   しかし上記の復旧事例では、この同じ操作によってコントローラー本体も再びファームウェア更新モードに入ることができました。
   これは実用上の復旧観察として扱うべきであり、公式に文書化されたコントローラー復旧方法ではありません。


9. Stock ファームウェアと Analogue ファームウェアを切り替える（要約）
---------------------------------------------------------------------

- コントローラーを Analogue コンソールに直接接続して使う場合（USB レシーバーなし）:

  - Analogue 専用ファームウェアをインストールします（第4節を参照）。
  - 第5節の手順で Analogue Dock / Duo とペアリングします。

- コントローラーを付属の 2.4G USB レシーバーと使う場合:

  - Stock PCE 2.4G ファームウェアをインストールします（第3節を参照）。
  - 必要に応じて USB レシーバーのファームウェアを更新します（第6節を参照）。
  - その後、第7節の手順でコントローラーとレシーバーを再ペアリングします。

常に覚えておいてください:

- Analogue ファームウェア = Analogue コンソールへ直接接続（レシーバーなし）。
- Stock ファームウェア = 2.4G USB レシーバーを使用し、レシーバーとペアリングが必要。

Notas de firmware del mando 8BitDo PCE 2.4G

Este mando admite DOS tipos de firmware diferentes:

1)  Firmware estándar 8BitDo PCE 2.4G (“stock”)
2)  Firmware especial Analogue para consolas Analogue (por ejemplo,
    Analogue Duo)

Lee esto si alguna vez cambias el firmware.

1. Tipos de firmware

A)  Firmware stock de PCE 2.4G

-   Funciona con el receptor USB 2.4G incluido.
-   La comunicación inalámbrica es: Mando <-> Receptor USB.
-   Después de instalar el firmware stock, debes volver a emparejar el
    mando con el receptor USB (véase la sección 7).

B)  Firmware Analogue

-   Diseñado para sistemas Analogue (como Analogue Duo).
-   El mando se conecta directamente a la radio 2.4G de la consola
    Analogue.
-   Cuando ejecuta firmware Analogue, NO se utiliza el receptor USB 2.4G
    incluido.
-   Si más tarde vuelves al firmware stock, el mando dejará de
    comunicarse directamente con la consola Analogue y deberá volver a
    emparejarse con el receptor USB.

2. Entrar en modo de actualización de firmware (mando)

Usa este procedimiento siempre que quieras cambiar el firmware (stock o
Analogue):

1.  Asegúrate de que el mando esté APAGADO.
2.  Mantén pulsado el botón SELECT.
3.  Mientras mantienes pulsado SELECT, pulsa brevemente el botón HOME
    una vez y luego suelta AMBOS botones inmediatamente.
4.  Comprueba que los LED azul y verde parpadeen al mismo tiempo
    (sincronizados).
    -   Azul y verde parpadeando juntos = modo de actualización de
        firmware.
5.  Conecta el mando a un ordenador con un cable USB.
6.  Aparecerá una nueva unidad flash USB (este es el almacenamiento
    interno del mando).

Ahora puedes copiar el archivo de firmware adecuado a esta unidad flash.

3. Instalar firmware stock (PCE 2.4G estándar)

Esta sección describe cómo instalar o reinstalar el firmware stock
estándar.

1.  Pon el mando en modo de actualización de firmware (véase la sección
    2).

2.  En tu ordenador, abre un navegador web y ve a:

        https://support.8bitdo.com/

3.  Descarga el paquete de firmware stock de PCE 2.4G, por ejemplo:

        8BitDo_PCE_Fw_V405.zip

    Enlace directo, si hace falta:

        https://download.8bitdo.com/Firmware/Controller/PCE-2.4g/8BitDo_PCE_Fw_V405.zip

4.  Extrae el archivo ZIP.

5.  Dentro de la carpeta extraída, busca el archivo de firmware del
    mando, por ejemplo:

        8BitDo_PCE_Fw_V405/Controller/PCE_24G_GamePad_V4.05.dat

6.  Copia el archivo de firmware del mando (por ejemplo,
    PCE_24G_GamePad_V4.05.dat) a la raíz de la unidad flash del mando.

7.  Espera un par de minutos para que la actualización se complete.

8.  Expulsa de forma segura la unidad flash desde el sistema operativo.

9.  Desconecta el cable USB.

10. Fuera de USB, mantén pulsado el botón HOME durante unos 3 segundos
    para que el mando salga completamente del modo de actualización / se
    apague.

11. Enciéndelo normalmente si lo deseas.

4. Instalar firmware Analogue (para consolas Analogue)

Esta sección describe cómo instalar o reinstalar el firmware específico
de Analogue para usarlo directamente con sistemas Analogue (como
Analogue Duo).

1.  Pon el mando en modo de actualización de firmware (véase la sección
    2).

2.  En tu ordenador, abre un navegador web y ve a:

        https://support.8bitdo.com/analogue/Dock/

3.  Descarga el paquete de firmware Analogue para este mando, por
    ejemplo:

        PCE_Fw_V5_01_For_Analogue.zip

    Enlace directo, si hace falta:

        https://download.8bitdo.com/Firmware/analogue/Dock/2.4g/PCE_Fw_V5_01_For_Analogue.zip

4.  Extrae el archivo ZIP.

5.  Dentro de la carpeta extraída, busca el archivo de firmware del
    mando, por ejemplo:

        PCE_Fw_V5_01_For_Analogue/PCE_Fw_V5_01_For_Analogue.dat

6.  Copia el archivo de firmware Analogue (por ejemplo,
    PCE_Fw_V5_01_For_Analogue.dat) a la raíz de la unidad flash del
    mando.

7.  Espera un par de minutos para que la actualización se complete.

8.  Expulsa de forma segura la unidad flash desde el sistema operativo.

9.  Desconecta el cable USB.

10. Mantén pulsado el botón HOME durante unos 3 segundos hasta que todos
    los LED se apaguen.

11. Actualización completa.

Cuando el firmware Analogue está instalado, el mando se emparejará
directamente con el sistema 2.4G de la consola Analogue, y no se
utilizará el receptor USB 2.4G incluido.

5. Emparejar el mando con Analogue Duo / Analogue Dock

Cuando el mando está ejecutando firmware Analogue, usa este
procedimiento para emparejarlo con el sistema inalámbrico Analogue:

1.  Pulsa el botón HOME para encender el mando.
2.  Mantén pulsado el botón SELECT durante unos 3 segundos.
    -   El LED azul empezará a parpadear rápidamente.
3.  Pulsa el botón de emparejamiento del Analogue Dock / Analogue Duo.
4.  Cuando el emparejamiento se complete, el LED azul del mando
    permanecerá fijo.
5.  Después del primer emparejamiento exitoso, el mando debería
    reconectarse automáticamente la próxima vez.

6. Poner el receptor USB en modo de actualización de firmware

El receptor USB 2.4G también tiene su propio firmware y se puede
actualizar.

Importante:

-   El receptor solo puede ponerse en modo de actualización mientras el
    mando esté ejecutando firmware STOCK y comunicándose con el
    receptor.
-   Con firmware Analogue, el receptor no se usa, por lo que su modo de
    actualización no puede activarse desde el mando.

Para poner el receptor USB en modo de actualización de firmware:

1.  Asegúrate de que el mando esté usando firmware stock y pueda
    conectarse al receptor.

2.  Conecta el receptor USB 2.4G a tu ordenador.

3.  Enciende el mando pulsando el botón HOME.

    -   Espera hasta que el mando y el receptor estén conectados (el LED
        del receptor debe permanecer fijo, no solo parpadeando).

4.  Ahora mantén pulsados los tres botones siguientes en el mando al
    mismo tiempo:

        SELECT + RUN + HOME

5.  Sigue manteniendo pulsados estos tres botones hasta que aparezca una
    NUEVA unidad flash USB en el ordenador.

    -   Esta nueva unidad es el receptor USB en modo de actualización de
        firmware.

Ubicación del archivo de firmware del receptor (paquete stock v4.05):

-   Después de extraer el ZIP de firmware stock
    (8BitDo_PCE_Fw_V405.zip), el archivo de firmware del receptor está
    aquí:

        8BitDo_PCE_Fw_V405/Receiver/PCE_24G_RR_V4.05.dat

6.  Abre la nueva unidad flash que apareció (el receptor).

7.  Copia el archivo de firmware del receptor:

        PCE_24G_RR_V4.05.dat

    a la raíz de la unidad flash del receptor.

8.  Espera un par de minutos para que la actualización se complete.

9.  Expulsa de forma segura la unidad flash desde el sistema operativo.

10. Desconecta el receptor USB y vuelve a conectarlo si hace falta.

Después de esto, el receptor USB estará ejecutando el firmware
actualizado.

7. Volver a emparejar el mando con el receptor USB (después de usar firmware Analogue)

Cada vez que cambies de firmware Analogue a firmware stock, DEBES volver
a emparejar el mando con su receptor USB. De lo contrario, no se
conectarán de forma inalámbrica.

Para emparejar el mando con el receptor USB:

1.  Conecta el receptor USB 2.4G a tu PC o consola.
    -   El LED azul del receptor parpadeará.
2.  Enciende el mando con el botón HOME.
3.  Mantén pulsado el botón SELECT durante unos 3 segundos.
    -   El LED azul del mando empezará a parpadear rápidamente.
4.  Mantén el mando cerca del receptor.
5.  Cuando el emparejamiento se complete, los LED azules tanto del mando
    como del receptor permanecerán fijos (azul estable).

Después de este paso, el mando y el receptor quedarán sincronizados con
firmware stock.

8. Notas de recuperación / desbrickeo (observaciones prácticas)

Estas notas se basan en comportamientos de recuperación observados en
situaciones reales durante la recuperación de firmware.

1.  Si el mando todavía entra en modo de actualización de firmware y se
    monta como una unidad flash USB, es probable que el bootloader siga
    funcionando.
2.  Después de copiar el archivo de firmware, expulsa siempre de forma
    segura la unidad flash del mando, desconecta el cable USB, y solo
    entonces mantén pulsado HOME durante unos 3 segundos fuera de la
    alimentación USB.
3.  En un caso de recuperación, flashear desde Windows funcionó
    correctamente, mientras que flashear desde Linux dejó el mando sin
    respuesta incluso después de sync y desmontaje correcto. Por eso,
    Windows es la opción más segura para este mando específico al
    recuperarlo de un cambio de firmware fallido.
4.  Si el mando parece muerto después de un cambio de firmware, déjalo
    cargando durante más tiempo antes de concluir que está brickeado.
    Una batería muy baja puede hacer que el diagnóstico sea engañoso.
5.  En un caso de cambio de firmware fallido, la combinación normal de
    actualización del mando (SELECT + HOME) dejó de funcionar. Sin
    embargo, mantener pulsado SELECT + RUN + HOME durante unos segundos
    hizo que el mando volviera a entrar en modo de actualización de
    firmware, con los LED azul y verde parpadeando juntos. Después de
    eso, al conectar el mando a una máquina con Windows y volver a
    flashear el firmware, la recuperación tuvo éxito.
6.  SELECT + RUN + HOME está pensado oficialmente para poner el receptor
    en modo de actualización de firmware cuando el mando está ejecutando
    firmware stock y está conectado al receptor. Sin embargo, en el caso
    de recuperación descrito arriba, esta misma combinación también
    permitió que el propio mando volviera al modo de actualización de
    firmware. Esto debe tratarse como una observación práctica de
    recuperación, no como un método oficial documentado de recuperación
    del mando.

9. Cambiar entre firmware stock y Analogue (resumen)

-   Para usar el mando directamente con una consola Analogue (sin
    receptor USB):
    -   Instala el firmware específico de Analogue (véase la sección 4).
    -   Empareja el mando con el Analogue Dock / Duo siguiendo los pasos
        de la sección 5.
-   Para usar el mando con el receptor USB 2.4G incluido:
    -   Instala el firmware stock de PCE 2.4G (véase la sección 3).
    -   Opcionalmente, actualiza el firmware del receptor USB (véase la
        sección 6).
    -   Luego vuelve a emparejar el mando y el receptor siguiendo los
        pasos de la sección 7.

Recuerda siempre:

-   Firmware Analogue = conexión directa a la consola Analogue (sin
    receptor).
-   Firmware stock = usa el receptor USB 2.4G y debe emparejarse con él.
